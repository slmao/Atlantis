# assets/

Empty by design.

Asset layout, formats, and the import/processing pipeline (likely owned by
Atlantis Tools — see
[docs/architecture/module_boundaries.md](../docs/architecture/module_boundaries.md#atlantis-tools))
are established by the spec that introduces asset handling, not invented
ahead of time.

Do not add asset files here without a linked spec and plan. See
[AGENTS.md](../AGENTS.md).
