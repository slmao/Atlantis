## Objective

Implement Spec 0058 R1–R8 as ruled:

- **Atlantis C# SDK** (`src/csharp/Atlantis.Gameplay/`), a managed .NET 10
  library that speaks `atlantis.remote/1` itself, with:
  - a reflective layer;
  - a typed layer generated from `worldSchema()` by the generator's new C#
    backend, committed.
- **The protocol pinned as a contract:** a reference document and
  conformance vectors generated by the C++ codec.
- **A C# beacon demo** run in a two-process ctest.

There is no engine change. R8's directories have zero changes, the
generated C++ header and `runFrame()` stay byte-identical, every golden is
unchanged, and Android never sees C#.

## Pre-drafting reading (cited, not restated)

Read at `origin/main` `1a273b1` (#238 merged).

1. **The wire** (`src/remote/src/codec.h`, `remote_server.cpp`,
   `remote_client.cpp`, `line_channel.h`, `session_file.h`):
   - **Framing and handshake:**
     - one JSON object per line (`\n`, a trailing `\r` dropped), 1 MiB
       line limit;
     - requests `{"id","method","params"}`, responses `{"id","result"}`
       or `{"id","error":{…}}`;
     - `hello{protocol,token}` first (`WrongProtocol`, `BadToken`,
       `HelloRequired`).
   - **Methods:**
     - `connection.{findEntity, listEntities, listComponents,

       unsubscribe, drainEvents, drainFailures}`, with params `entity`,
       `address`, `command`, `commands`, `filter`, `subscription`;
     - `control.{status, pause, resume, diagnostics(after,max),
       step(request)}` — `step` is parked until its frame completes.
   - **Value encoding** (`codec.h`'s comment):
     - in-band results `{"ok"}` / `{"err"}`;
     - the client assigns ids from 1 and pipelines by sending before
       awaiting.
   - **Size:** about 990 lines of codec, 470 of client half and 60 of
     session file.
2. **Codec access for tests:** `atlantis_remote_wire` (codec + JSON) and
   `${CMAKE_SOURCE_DIR}/src/remote/src` on the include path, as

   `ServedWorld` serves a baked fixture over a real `RemoteServer`.
3. **The generator** (`src/tools/sdk_codegen/`):
   - `generateBindings()`, the pure C++ backend, and
     `worldBindingOptions()`;
   - the tool takes `--out` only;
   - `tests/tools/sdk_codegen/` holds the staleness tests (J4's
     `.expected`) and the synthetic table.
4. **The 0057 two-process test** (`tests/gameplay_sdk/gameplay_e2e_tests.cpp`):
   - helpers `Child`, `windowsOf`, `stepLines`, `runOnce`;
   - built only if `WIN32 AND ATLANTIS_BUILD_EXAMPLES`.
5. **Gating precedents:**
   - Bistro content-gating (`if(DEFINED ATLANTIS_bistro_scene_TARGET)`,

   - required tools fail configure (`slangc`, `spirv-val`);
   - host tools sit under `if(NOT ANDROID)`;
   - Gradle passes `-DATLANTIS_BUILD_TESTS=OFF -DATLANTIS_BUILD_EXAMPLES=OFF`

code implements it, citing the C++ source as authoritative where they could
differ:

  - framing and limits;

  - the value encoding (every `PropertyValue` alternative, floats,

**P3 — Conformance vectors** (R6; Q8).

- **`codec_vectors.jsonl`:** one line per case,
  `{"case":"<name>","type":"<PropertyValue|Command|Event|…>","wire":<the C++ codec's encoding>}`.
  - **Coverage:**
    - every `PropertyValue` alternative and edge: `0`, `UINT64_MAX`,
      `-0.0f`, the float extremes, NaN, ±Inf, a negative enum, `Absent`,
      both GUID kinds;
    - every command and event;
    - failures, tickets, filters (empty, kinds, entity, component);
    - a schema (`worldSchema()`);
    - `RuntimeStatus`, `StepRequest`, `FrameReport`, `DiagnosticBatch`.
  - **C# checks two things:**
    - decoding each wire value and re-encoding it gives the **same
      bytes** (the codec's canonical form);
    - a hand-written table of expectations for the edge cases decodes to
      exactly those C# values.
- **`sdk_transcripts.jsonl`:** one line per named scenario,
  `{"scenario":"<name>","submissions":[{"transaction":bool,"commands":[…wire…]}]}`.
  - The scenarios are the typed and reflective operations of P6:
    - `typed.set.intensity`, `typed.add.light`, `typed.spawn.beacon`;
    - `reflective.add.valued`, `reflective.set.path`, `mixed.transaction`;
    - a bare add, remove and destroy.
  - **Source:** the C++ Gameplay SDK over an InProcess `RecordingConnection`
    on the fixture scene (the 0057 test pattern), encoded by the C++ codec.
  - **Use:** C# runs the same scenarios against the fixture server in
    `--record` mode and compares what the server received (R3 parity).
- **Generation and staleness:** the C++ test `atlantis_csharp_conformance_tests`
  builds both files in memory and compares them byte for byte with the
  committed ones. On a mismatch it writes `<build>/csharp_conformance/<name>.expected`
  and fails with the copy command (the 0057 J4 pattern). It runs without
  .NET. Both files are `eol=lf`.

**P4 — The GPU-free fixture server** (Q7). `tests/csharp/fixture_server/main.cpp`
→ `atlantis_csharp_fixture_server`, test-only, Windows and host only:

- **What it serves:** the Spec 0054 fixture scene (cooked and decoded in a
  temp directory, as `tests/remote/remote_fixture.h` does), baked, behind a
  boundary, an InProcess endpoint and a real `RemoteServer` on
  `127.0.0.1:0`.
- **Usage:** `atlantis_csharp_fixture_server --session-file <path>
  [--record <path>] [--mutate <name>]`.
- **Its control** implements `RuntimeControl` like
  `tests/editor/editor_fixture.h`'s fake:
  - a frame applies pending commands unless paused;
  - a step releases exactly its frames and completes with a
    `FrameReport` whose frame data is empty (there is no renderer) and
    whose `frame` counts;
  - `status` and `diagnostics` are empty.
- **Frames:** a frame runs every 2 ms, followed by `poll()`. Answers
  therefore arrive at frame boundaries, as in the Runtime.
- **`--record`:** every client connection is wrapped so `submit` and
  `submitTransaction` append one JSON line (P3's submission shape) to the
  file.
- **`--mutate`:** the wrapper serves a modified schema for the
  compatibility tests: `light-version`, `light-kind-constant`,
  `camera-fog-version`, `light-intensity-readonly`, `light-extra-field`.
- **Lifetime:** it writes the session file when listening, exits 0 when
  its standard input closes, and removes the session file. The C# test
  program starts it and holds its standard input.

**P5 — The C# generator backend** (R2; ruling Q2; ADR-0112 D3).

- **API:** `generateCSharpBindings(schema, CSharpOptions)` returns
  `Result<std::string, CodegenFailure>`. It is pure, deterministic, LF
  only and has no timestamp; `CSharpOptions` carries the module prefix,
  the namespace (`Atlantis.Gameplay.World`), the source and the
  regeneration line.
  - `worldCSharpOptions()` is shared by the tool and the test.
  - The tool: `atlantis_sdk_codegen [--lang cpp|csharp] --out <path>`,
    `cpp` by default, so the 0057 command is unchanged.
- **Output shape** (normative layout; spellings are the implementation's):

  ```csharp
  // <auto-generated> atlantis_sdk_codegen from world::worldSchema() -- do not edit. Regenerate: … </auto-generated>
  #nullable enable
  namespace Atlantis.Gameplay.World;
  public enum LightKind : long { Directional = 0, Point = 1 }
  public record struct Light : IComponent<Light> {
    public LightKind Kind { get; set; } public System.Numerics.Vector3 Color { get; set; } …
    static TypeBinding IComponent<Light>.Binding => Bindings.Types[4];
    static ReadOnlySpan<FieldId> IComponent<Light>.Leaves => …;              // leavesOf order
    static void IComponent<Light>.Write(in Light v, Span<PropertyValue> out) { … }
    static bool IComponent<Light>.TryRead(ReadOnlySpan<PropertyValue> in, out Light v) { … }
    static bool IComponent<Light>.AllEditable => true;
  }
  public static class Fields { public static class Light {
    public static readonly Field<global::Atlantis.Gameplay.World.Light, float> Intensity = new(TypeId, FieldId, "Light.intensity"); … }
    public static class Camera { public static class Fog { … } … } }
  public static class Bindings { public static readonly TypeBinding[] Types = { … }; }  // ids, kinds, flags, versions, constants, ZeroIsDeclared
  ```

- **Type map:** as ruled. `EntityGuid` and `AssetGuid` are the library's
  record structs; a non-Editable leaf gets `ReadOnlyField<,>`.
- **Name rules** (the ADR-0111 D5 rule extended):
  - types keep their schema names;
  - fields become PascalCase (first letter upper-cased);
  - generation fails for:
    - two fields of one type mapping to the same name;
    - a member named like its enclosing type (C# CS0542);
    - a C# keyword (the full reserved list);
    - a generator-reserved name (`Fields`, `Bindings`).
- **Committed outputs:**
  - `src/csharp/Atlantis.Gameplay/Generated/World.g.cs`;
  - `tests/csharp/Generated/Synthetic.g.cs` (namespace
    `Atlantis.Gameplay.Synthetic`, from 0057's synthetic table).
- **Staleness:** the existing `atlantis_sdk_codegen_tests` gains both
  checks (J4's `.expected`), plus determinism, LF, the name-rule refusals,
  exact enum values, one handle per leaf, and the C++ outputs unchanged.
  No .NET is needed.

**P6 — The C# library** (R1, R3, R4; rulings Q4, Q5; ADR-0112 D1, D4, D5).
`src/csharp/Atlantis.Gameplay/`, namespace `Atlantis.Gameplay`:

- **Values:**
  - `EntityGuid`, `AssetGuid` (`readonly record struct` over `Guid`;
    parse and format RFC 9562 text only);
  - `TypeId`, `FieldId`;
  - `PropertyValue` (a tagged `readonly struct`, one alternative per
    wire tag);
  - `PropertyAddress`;
  - `Command` and `Event` (sealed record hierarchies);
  - `CommandTicket`, `TransactionTicket` (`Contains`), `CommandFailure`;
  - `AccessError`, `ControlError` (enums with the wire names);
  - `EventKind`, `EventFilter`;
  - `RuntimeStatus`, `StepRequest`, `FrameReport`, `FrameData`,
    `FramePointLight`, `FrameDirectionalLight`, `CapturedImage`.
- **`Atlantis.Gameplay.Remote`:**
  - `SessionFile` (`Resolve(explicit, env)`, `Read`; the same order and
    default path as C++);
  - `Codec` (`System.Text.Json`; floats written by `float.ToString("R",
    InvariantCulture)`, `"nan"`/`"inf"`/`"-inf"`; ids `"0x"` + 16 hex;
    `u64` decimal strings);
  - `RemoteSession`:
    - `Connect(SessionInfo)`: `TcpClient`, `hello`, then the schema
      fetch;
    - JSON-lines framing with the 1 MiB limit;
    - ids from 1;
    - `Send` / `Await` for pipelining;
    - a response timeout (default 120 s, as C++);
    - exposes `Control` and the raw calls.
  - **Exceptions:** `RemoteException` (`ConnectFailed`, `BadToken`,
    `WrongProtocol`, `Disconnected`, `Timeout`, `ProtocolError`).
- **Reflective layer:**
  - `GameplayWorld(RemoteSession)`:
    - `Exists`, `Entities`, `Components`;
    - `EntitiesWith(params string[])`, `EntitiesWith(params TypeId[])`;
    - `Get(entity, path)`, `Get(address)`, `Set(entity, path, value)`;
    - `ReadComponent(entity, type)`;
    - `Submit(Transaction)`, `Submit(Command)`;
    - `Subscribe(filter)` returning an `IDisposable` `Subscription`;
    - `DrainFailures`.
  - **Names** resolve with the same grammar as `connection::text` (short or
    qualified type names; full paths), ported in `SchemaText`.
  - **`Transaction`:** a builder resolved whole at `Submit`. Any name or
    binding error throws before anything is sent, so there is no ticket.
  - **`FailureLog`.**
  - **Batching:** `ReadComponent`, `Get<T>` and `EntitiesWith` pipeline
    their queries.
- **Typed layer:**
  - `Get<T>(entity) where T : struct, IComponent<T>` (static abstract
    interface members: no reflection);
  - `Get(entity, Field<TC,TV>)` and `Get(entity, ReadOnlyField<TC,TV>)`;
  - `Set(entity, Field<TC,TV>, TV)` — no overload takes a
    `ReadOnlyField`;
  - `EntitiesWith<T1>()` … `EntitiesWith<T1,T2,T3>()`;
  - `Decode(event, field)`;
  - `Transaction.Add<T>(entity, T)` with an `AllEditable` check: a
    `where` constraint cannot test a static bool, so a generated
    `IEditableComponent<T>` marker interface is emitted only on
    all-Editable types and `Add(entity, T)` requires it;
  - `Add<T>(entity)` (bare), `Remove<T>`, typed `Set`.
- **Compatibility** (R4): per type, recursive, cached per `GameplayWorld`;
  a mismatch throws `SchemaMismatchException` and sends nothing.
- **Errors** (ruling Q5):
  - `RemoteException`, `UnknownNameException`
    (`UnknownType`/`UnknownField`/`NotALeaf`) and `SchemaMismatchException`
    are thrown;
  - a command's World refusal comes back as a value, by ticket;
  - a query's World refusal (e.g. `ComponentMissing` on a `Get`) throws
    `RefusedException(AccessError)` — the Plan's reading, since the ruling's
    "World refusals return as values, by ticket" names commands (J7).
- **Threading:** a `RemoteSession` and its `GameplayWorld` are not
  thread-safe, and say so in their doc comments. Async is not
  implemented.

**P8 — The C# beacon demo** (R5; ruling Q6). `examples/csharp/GameplayDemo/`
→ `GameplayDemo.dll`:

- **Usage:** `dotnet GameplayDemo.dll [--session <path>] [--steps <K>]
  [--capture-dir <dir>]`, with exit codes 0/1/2/3 as the C++ demo.
- **The loop:** P6 of Plan 0057, typed.
  - **Beacon:** `58005800-0000-4000-8000-0000000000b1`; a leftover one is
    reported with exit 1.
  - **Steps:** connect (bindings checked); find; pause and capture a
    baseline; spawn in one transaction (Light before WorldMatrix); K logic
    steps; refuse (NaN colour, nothing applied); capture (PNG bytes differ
    from the baseline); destroy; resume.
- **The trajectory — no trigonometry, deterministic.** For step `k`:
  - `p = 4f * k / K` (IEEE single precision);
  - `side = (int)p % 4`, `u = p - (int)p`;
  - the position is `Lerp(corner[side], corner[(side + 1) % 4], u)` over
    the square `(1.5,2,1.5)`, `(-1.5,2,1.5)`, `(-1.5,2,-1.5)`,
    `(1.5,2,-1.5)`, the same orbit radius and height as the C++ demo, in
    view;
  - the intensity is `4f + 2f * (1f - MathF.Abs(2f * u - 1f))`.
  - Only `+ - * /`, `Abs` and casts are used, so every value is
    reproducible on every run. With the default `K = 8`, `u ∈ {0, 0.5}`
    and every position and intensity is exactly representable (corners,
    edge midpoints, 4 or 6).
- **Output:** one line per step. It includes no frame numbers, paths or
  time, so the output is identical run to run.

**P9 — C# tests** (R2–R6; ruling Q7). `tests/csharp/Atlantis.Gameplay.Tests/`
is one console program. Each suite is a function that returns normally or
throws `AssertionFailed`; `Main` runs the suite named on the command line
and returns 0 or 1, printing each check's name.

- **Suites:**
  - **`codec`:** P3's vectors — byte-identical round trip, and the edge
    expectations.
  - **`session`:** the session-file parser (valid, missing fields, wrong
    protocol, path resolution order).
  - **`generated`:**
    - the bindings in `World.g.cs` and `Synthetic.g.cs` equal the schema
      the fixture server serves;
    - PascalCase handles and `ReadOnlyField` types;
    - value initialization: zeros, `null`, enum value 0, `ZeroIsDeclared`
      (Mode false, Phase true, LightKind true and `== Directional`).
  - **`live.connection`** (against the fixture server): every
    `connection.*` and `control.*` method, `hello` failures (bad token,
    wrong protocol), framing (a request after the line limit
    disconnects), pipelining order.
  - **`live.reflective`:** get/set by path and id, `ReadComponent`,
    `EntitiesWith`, transactions all or nothing, name errors sending
    nothing, refusals by ticket, subscriptions and `IDisposable`.
  - **`live.typed`:**
    - `Get<T>`, field `Get`/`Set`, `Add` and the bare add, `Decode`;
    - zeros vs World defaults;
    - **parity:** the P3 scenarios run in `--record` mode equal
      `sdk_transcripts.jsonl`.
  - **`live.compat`:** one fixture server per `--mutate` case. The mutated
    type is refused, recursively; unrelated types work; a mixed
    transaction sends nothing.
  - **`live.isolation`:** two sessions on one fixture server; the mixed
    read and the consistent read, with B's step completing between A's
    leaves (Spec 0057 R10's contract over C#).
- **Compile probes** (J5): `tests/csharp/probes/Probe.csproj` is built three
  times with `-p:DefineConstants=…` (`Set` on a `ReadOnlyField`, `Add` of a
  type with a read-only leaf, `Set` with the wrong value type) and three
  more times as their compiling twins.
  - Each is a ctest whose failing variant passes only if the output

## Risks

- **No .NET SDK yet** on this machine. M3 cannot start without it. M1–M2
  are deliberately .NET-free so work can proceed.
- **VS-bundled SDKs may be a newer feature band** (2xx–4xx) than
  `global.json`'s 1xx with `latestPatch`. Then `dotnet` refuses them, and
  the 1xx SDK must be installed side by side (J2).
- **Float text across runtimes:** .NET's shortest round-trip `float`
  formatting must match the C++ shortest form byte for byte on the
  vectors. If an edge case differs (exponent notation, `-0`), M3 reports
  it before changing anything; the C# encoder is then adjusted to the C++
  form, which is the reference.
- **Fixture timing:** frames every 2 ms make answers fast. The isolation
  suite orders B's step by waiting for its completion, not by timing.
- **`dotnet build` incrementality inside CMake:** a source glob with
  `CONFIGURE_DEPENDS` re-checks on every build. A changed `.g.cs` is in the
  glob.

## Joint Review decisions — ruled (Joint Human Review, slmao, 2026-10-09, PR #239)

All thirteen were ruled as recommended. Spec 0058 is not corrected, and
ADR-0112 and ADR-0113 are unchanged. The rejected alternatives are kept as
the record of what was weighed.

- **J1 — The Spec's "eight directories".** **Ruled (2026-10-09): R8's seven
  plus `examples/gameplay_demo/`.**
  - **The eight:** `src/runtime/`, `src/world/`, `src/connection/`,
    `src/remote/`, `src/cli/`, `src/editor/`, `src/gameplay_sdk/` and
    `examples/gameplay_demo/` (the C++ client unchanged).
  - **Also guarded:** `shaders/` and `assets/`, at every gate.
  - **Recorded:** R8's enumeration of seven is a slip in the Spec; no Spec
    Correction is raised.
  - **Rejected:** guarding R8's seven only.
- **J2 — `global.json`.** **Ruled (2026-10-09): `10.0.111` with
  `rollForward: latestPatch`**, ADR-0113's 1xx band.
  - The implementing machine must install a 1xx-band SDK (side by side
    with any VS-bundled newer band).
  - M3 records the exact version installed.
  - **Rejected:** `latestFeature` (it would change ADR-0113 D1's band).
- **J3 — Conformance vectors.** **Ruled (2026-10-09): as P3.**
  - The codec vectors are checked by a byte-identical round trip plus
    hand-written edge expectations.
  - Parity uses command transcripts recorded from the C++ SDK over
    InProcess, compared with what the fixture server records from C#.
  - One C++ test generates both files and checks them for staleness.
- **J4 — The fixture server.** **Ruled (2026-10-09): as P4.**
  - A separate C++ executable launched by the C# tests.
  - It exits when its standard input closes.
  - A 2 ms frame tick.
  - `--record` and `--mutate`.

  **Rejected:** C# tests only against a real Runtime (GPU-bound, with no
  schema mutation or recording).
- **J5 — C# compile probes.** **Ruled (2026-10-09): as recommended.** Three
  failing builds with compiling twins (a `ReadOnlyField` set, a
  non-Editable `Add`, the wrong value type), each matched to `Probe.cs`'s
  own error line.
- **J6 — `IComponent<TSelf>`.** **Ruled (2026-10-09): as recommended.**
  Static abstract interface members carry each type's binding, leaves and
  codec, so `Get<T>` uses no reflection. `IEditableComponent<T>` marks the
  all-Editable types `Add(entity, T)` accepts.
- **J7 — Errors.** **Ruled (2026-10-09): query refusals throw
  `RefusedException(AccessError)`; command refusals come back as values,
  by ticket.**
  - **Recorded reading:** ruling Q5's "World refusals return as values, by
    ticket" covers commands only. A ticket exists only for a command; a
    query has no ticket channel, so its refusal is thrown.
  - **Rejected:** `TryGet` patterns for queries.
- **J8 — Build placement.** **Ruled (2026-10-09): as recommended.**
  `Directory.Build.props` routes outputs under the CMake build tree when
  CMake builds, and to `bin/`/`obj/` (git-ignored) when a developer runs
  `dotnet build` directly.
- **J9 — The rules check.** **Ruled (2026-10-09): as recommended.** A
  `cmake -P` ctest — no NuGet, no native interop, the `eol` rules — that
  runs with or without .NET.
- **J10 — The two-process case.** **Ruled (2026-10-09): as recommended.**
  - One new test case in `tests/gameplay_sdk/gameplay_e2e_tests.cpp`,
    reusing that file's helpers, with no third copy.
  - Compiled in only when C# is enabled; `SKIP` otherwise.
  - The 0057 case is untouched.
- **J11 — Acceptance.** **Ruled (2026-10-09): the human C# demo run only.**
  No whitelist-scene or Android-emulator re-run, because the engine is
  untouched (0057 J9's reasoning).
- **J12 — Docs.** **Ruled (2026-10-09): the split as recommended.**
  - **With the implementation PR (normative):** AGENTS.md (the C# SDK
    module, the protocol's status) and `module_boundaries.md` (the C# SDK
    section, Tools).
  - **After merge:** the narratives (registry, Spec Related Plan,
    blueprint).
- **J13 — The protocol reference.** **Ruled (2026-10-09): descriptive.**
  - The document describes the protocol as the code implements it. A
    difference between the two is a documentation bug, fixed in the same
    PR, with the code taken as right.
  - A change to the protocol's behaviour is a different thing. It still
    needs a Spec and a new ADR superseding ADR-0106 (Spec 0058 ruling Q8).
    The two are kept distinct.
